# Images

## logo.jpg - REQUIRED

Put the AO Luxe Events logo file here, named exactly `logo.jpg`.

Use the original file as supplied. Do **not** redraw it, recolour it,
crop it or export it from another program - the site scales it
proportionally wherever it appears.

Until this file exists, the logo will not display on the site.

## team/ - founder and team photos

Referenced from `/lib/team.ts`:

- `owner-photo.jpg` - the founder, portrait (roughly 4:5)
- `team-group.jpg` - the team group shot, portrait (roughly 3:4)

The About page shows these two photographs only; there are no
individual team member cards. If a file is missing, the site shows a
gold monogram placeholder rather than a broken image.

Both were resized from the client's originals for web use. The full
resolution files are unchanged on the client's own machine.
